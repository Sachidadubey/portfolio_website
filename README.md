## ✨ Features

- **Animated Custom Cursor** — dual-ring cursor with smooth lag effect
- **Scroll Progress Bar** — thin neon bar at the top showing scroll depth
- **Canvas Particle Background** — animated dot-grid on HTML5 Canvas
- **Intersection Observer Animations** — elements slide in on scroll
- **Scroll-Aware Navbar** — shrinks and changes opacity on scroll
- **Mobile Responsive** — fully responsive across all screen sizes
- **Zero Dependencies** — no npm, no bundler, no frameworks
